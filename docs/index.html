PAPER REVIEW WORKFLOW

PaperStudio

论文投前诊断与改稿工作流：把「感觉有创新」压成「审稿人能复述的机制、可证伪的证据，以及与成果匹配的期刊」。

四段诊断

A · 解剖

拆清研究问题、核心机制与最多三个硬核卖点，要求每个卖点都能写出动机、设计和验证。

B · 压力测试

从审稿人视角追问证据链、对照实验、指标来源、数据集划分和结论边界。

C · 判决

判断论文当前能否投、适合哪个期刊梯度，以及哪些问题必须在投稿前关闭。

P · 改稿

通过卖点重构、防守补丁和语体校准完成修订；没有来源的指标一律标为待核验。

工作闸门

  1. A 解剖
  2. P1 灵魂拷问
  3. B 压力测试
  4. C 判决
  5. P3 防守补丁
  6. P4 语体校准
  7. 格式检查
  8. 授权投稿

公开范围

本页只介绍工作流。论文正文、诊断档案、实验记录、投稿材料与个人稿件路径不在这里公开。
