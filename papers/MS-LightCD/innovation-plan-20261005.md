## 先看这一部分：不用懂代码也能理解的说明

### A．论文原本要解决什么？

让电脑同时看“同一地点早期和晚期的两张遥感照片”，把新建、拆除等建筑变化的位置标出来。输出通常是一张黑白图，白色表示预测有变化，黑色表示预测没变化。光照、阴影、季节造成的颜色不同，不一定是建筑变化。

原论文追求的是：使用较小的网络，兼顾变化检测效果与设备上的推理速度。不是证明自己在每一项指标上都比现有模型更好，也不能把“轻量级”理解成已经比 TinyCD 更小。

### B．原模型里面的五个环节

```text
早期照片 + 晚期照片
        ↓
RepViT-M0.9：用同一套特征提取器看两张图
        ↓
四尺度特征：同时保留细节和较大范围的信息
        ↓
差分门控：比较两张图，并调整不同位置的差异响应
        ↓
FPN 多尺度融合：把细节信息与较深层的信息结合
        ↓
轻量解码器：还原成逐像素的变化区域图
```

“孪生、共享权重”的意思是两张图使用同一套特征提取规则，而不是给两张图各自训练一套完全不同的规则。它并不保证影像已经配准，也不保证每个特征通道都有完全对齐的语义。

原门控大致做两件事：给原始差异加权，再加上一条学习出来的修正信息。这个修正分支能帮助发现变化，也有能力在没有真实变化的位置产生响应。

### C．原来哪些东西有价值，哪些还不够？

现有内部实验显示，多尺度配置比只使用最深层的单尺度配置效果好；但这项比较还同时改变了空间分辨率与解码容量，不能把全部增益只归给一个融合算子。

原门控在 LEVIR-CD 上有帮助，在 WHU-CD 上却不稳定；配对与非配对对照也没有证实通道配对的性能优势。因此，问题不是“所有工作都白做了”，而是“门控这项设计为什么有效、什么时候会失效”的证据还不够。

### D．今晚到底加什么？

不增加第二个大型骨干，不接入 DINO、SAM 或另一个 Transformer 大模型。保留 RepViT、四尺度、FPN 和解码器，只把中间的旧门控换成一个自定义的小模块，暂名“零参考中心化调制”。

它同时问两个问题：

1. “眼前这组真实差异，会让我产生多大的响应？”
2. “保留同样的内容特征，但把差异设为零，我本身还会产生多大的响应？”

然后用第一个响应减去第二个响应，得到校准后的修正信息，再与原始差异结合。类似称重时先扣除底数。这个比喻只解释相减操作，不表示模块真的知道地面真相，也不表示它能消除所有阴影或光照干扰。

这里的“零参考”在特征里计算，不是生成一张新的遥感图片，也不是增加人工标注。实际分支和零参考分支共享同一套参数。

### E．潜在创新在哪里？

潜在贡献不是“又加了一层卷积”，而是检验一个具体设计原则：先消除模块在零差异条件下的自身响应，再让它修正真实差异。

它带来两个可检验的结构性质：完全相同的输入特征在这个模块中产生零差异输出；交换早晚两组特征，模块输出不变。不过，对称结构、门控和参考校准都有相邻研究，不能把这些概念单独称为首创。

要写成论文贡献，还必须证明：这个具体设计与已有方法有实质区别；减少误报时没有明显增加漏报；在不同数据集、不同随机种子上可重复；额外计算开销可以接受。今晚只做第一轮效果筛查，不完成全部创新证明。

### F．四组实验分别是什么？

| 顺序 | 数据集 | 版本 | 要回答的问题 |
|---|---|---|---|

### G．训练时那些数字是什么意思？

| 名词 | 直白解释 | 今晚设置 |
|---|---|---|
| 训练集 | 带答案的练习题，用来调整网络参数 | 沿用原划分 |
| 验证集 | 阶段测验，用来选保存哪一轮模型 | 每轮评估 |
| 测试集 | 原本用于最终报告的考试题 | 今晚不访问；历史使用情况须如实披露 |
| epoch | 把训练集完整学习一遍 | 每组 40 遍 |
| batch | 一次送进显卡的一小批样本 | 16 对照片，不是 16 张单图 |
| seed | 固定随机起点的编号，便于控制比较条件 | 42；并不保证所有 CUDA 运算逐位相同 |
| F1 | 综合考虑误报和漏报的指标 | 越高通常越好，但不能只看它 |
| Precision | 报出来的变化中，有多少是真的 | 关注“别乱报” |
| Recall | 真正的变化中，有多少找到了 | 关注“别漏掉” |
| checkpoint | 某一时刻保存的网络参数 | `best.pt` 保存验证 F1 最好的那一轮 |

计算机会学习网络内部的数值参数，但不会自动证明研究创新，也不会自动写出可靠的论文结论。

## 2．唯一主假设：内容条件下的零参考校准

暂名：Zero-reference Centered Modulation，零参考中心化调制。这个名字只是实验标签，不主张首创。

对同尺度双时相特征定义：

```latex
A=|X-Y|,\qquad S=\frac{X+Y}{2}
R=h_\theta(A,S)-h_\theta(0,S)
D=A+\sigma(\alpha)\,\sigma(g_\phi(R))\odot R
```

`h` 为分组 3×3 卷积、BN、SiLU、1×1 卷积。实际响应与零差分参考在同一次共享前向中计算。`sigmoid(alpha)` 初始为 0.1。

| 动机 | 设计 | 必须观察的验证证据 |
|---|---|---|
| 普通残差能够在没有时相差异时产生内容响应 | 减去同一内容条件下的零差分响应 | 特征级零响应测试；空变化验证切片的误报像素是否下降 |
| 仅逐元素乘法限制局部弱差异位置的修正能力 | 保留经过局部卷积的校准残差 | 低变化占比切片召回率不因误报抑制而明显下降 |
| 变化有无不应依赖输入时相顺序 | 输入采用绝对差分及均值 | 交换时相的输出一致性；它是结构性质，不单独包装为首创 |

理论边界：

1. 在该特征模块内，`D(X,X)=0`，且 `D(X,Y)=D(Y,X)`。
2. 非线性 `h` 才能保留内容条件效应；若 `h` 为线性映射，减法会直接抵消内容项。
3. 零特征响应不等于整网零误报。解码器偏置以及真实影像的光照、阴影、配准扰动仍会产生问题。
4. 这是结构性“零差分参考”，不是具有可识别因果效应的反事实推断。正文不能直接宣称因果去偏。
5. 卷积残差也能扩散伪变化；是否利大于弊必须由验证集决定。

## 3．已有工作的边界

有限检索已发现相邻思想，不能据此承诺“全新”“首次”：

- [Self-Pair，WACV 2023](https://arxiv.org/abs/2212.10236)：由单时相数据构造配对监督，研究重点是数据生成，不是此处的模块内零响应相减。
- [SemDINO，2026，v1](https://arxiv.org/html/2606.09772v1)：包含双向时相交互和零初始化可学习门控。因此，时相对称和稳定残差初始化已有明确相关研究。
- [IGARSS 2026 会议条目](https://www.2020.lagirs.org/view_paper.php?PaperNum=1211&SessionID=1411)：出现 Counterfactual-Guided Contrastive Learning for Robust Change Detection。本轮仅核得会议题录，没有据此推断其完整方法；提出创新声称前仍需取得全文排除实质重合。

当前可研究的是“上述具体校准算子在轻量级多尺度变化检测中的作用”，不是把几个已有术语组合成创新点。

## 4．训练前冻结的试验协议

台式机 GPU：已实机核验为 RTX 4070 SUPER，12 GB 显存。环境：Python 3.12.6、PyTorch 2.6.0+cu124、timm 1.0.27。

| 项目 | 本轮规定 |
|---|---|
| 数据集 | WHU-CD、LEVIR-CD，沿用既有 train/val 划分 |
| 变体 | 中心化候选；等参数未中心化对照 |
| 对照严格性 | 相同层、初始参数、输入表示、双分支前向与 BN 统计；仅移除零参考相减 |
| 预算 | seed 42；每组 40 个 epoch；共 4 组，顺序执行 |
| 训练配置 | RepViT-M0.9 预训练；256×256；batch 16；AdamW；初始学习率 5e-4；余弦调度；原 CombinedLoss；AMP |
| 选模 | 验证集正类 F1 最大，平分取较早 epoch |
| 诊断 | 在同一选中 checkpoint 上报告空切片误报像素、低变化占比召回；不能分别挑最有利 epoch |
| 低变化占比 | `0 < 变化像素占比 <= 1%`，不将其等同于实例级“小建筑” |
| 测试集 | 不建立 test loader、不自动测 test |
| 运行限制 | 每组最长 2 小时；15 分钟无进度则停止自有训练子进程；整个队列最长 30,000 秒 |
| 失败处理 | 遇错误停止队列；不自动重试、不改超参、不自动扩种子 |

冻结的晋级筛查标准（不是显著性检验）：

1. 两数据集上，中心化相对未中心化的验证 F1 均不降低超过 0.2 个百分点；两者平均增益至少 0.2 个百分点。
2. WHU-CD 空变化切片的误报像素至少减少 10%。若分母为零，不能用比值宣称通过，需人工复核。
3. 低变化占比组召回率不下降超过 0.5 个百分点；该分组必须存在。
4. 参数量不超过旧完整门控模型的 1.05 倍。计算量和设备延迟仍要另测；参数接近不代表运行时间接近。

通过后才讨论 3 种子、直接差分新基线、跨域／扰动诊断与端侧部署。即便胜过未中心化对照，也不能替代与直接差分及 TinyCD 等强轻量方法的同协议比较。若未通过，保留失败记录，不在论文中选择性隐藏。
