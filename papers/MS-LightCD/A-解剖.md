## 1. 真实场景里的真问题（去包装）

**使用方与决策**：土地利用监管 / 城市更新 / 灾后清查，要在配准双时相光学图上标建筑新增与拆除。漏检散布小建筑 = 漏管；虚警 = 误报工单。本文**不**承担无人机违建执法。

**图像与目标的物理事实**（表 1 + §3.1）：

- LEVIR-CD：Google Earth、美国得州、0.5 m、637 对 1024×1024、变化像素 4.20%、官方无重叠裁 256×256 → 7120 / 1024 / 2048；光照、阴影、物候
- WHU-CD：克赖斯特彻奇震后航空、0.3 m、覆盖 20.5 km²、官方空间不交叠测试区 2760 对；训练 4536 / 验证 504（从官方 512 父块按种子 42 划 10%）；大面积工商业拆除/新建
- 训练输入：双时相 RGB 256×256，已配准

**可观察的失败模式**：

1. **失败 A 小目标/边界**：深层连续下采样后，微小建筑与高频边界响应衰减（摘要/引言；图 7 困难案例完全漏检细长低对比度结构）
2. **失败 B 弱变化 vs 伪变化**：绝对差分对低对比真实变化响应弱，配准残差/光照/物候被映射为伪变化；加法残差可补召回，也在空背景加虚警（式 5 讨论；LEVIR 精确率 −0.54；WHU 无变化切片虚警约 2.4 倍）
3. **失败 C 不可归因 + 无板端**：轻量文献把骨干、金字塔、差分注意力混堆且协议不一；多报 Params/FLOPs，缺指定板、指定精度的模型推理时延

**不是问题的问题**：

- 不在 LEVIR 上全面超过 TinyCD（文献 F1 91.05 / 0.28 M vs 本文 90.68±0.01 / 5.42 M）
- 不把「多尺度 × 门控」写成强协同（交互效应 −0.33 个百分点 F1，小于单尺度标准差 0.40）
- 不把门控写成跨数据集伪变化抑制
- 不把违建小样本写进本刊引言
- 不把推理期重参数化折叠当独立贡献（§2.2 已声明）

**一句话问题定义**：

> 在轻量约束下，把「精度涨点来自多尺度还是来自门控」说清楚，并标定门控的数据集边界与板端模型时延。

## 2. 输入—处理—输出逻辑链

| 阶段 | 内容 | 形状 / 口径 |
|------|------|-------------|
| 输入 | 配准双时相 RGB | 训练/推理 256×256 |
| 预处理 | 官方切片；AMP；AdamW 40 epoch，bs=16 | 种子 42 / 123 / 3407；ImageNet 预训练 RepViT-M0.9 |
| 编码器 | 共享权重 RepViT-M0.9，四尺度 | 48/96/192/384 通道；H/4、H/8、H/16、H/32 |
| 变化表征 | 绝对差分 A；PSDG：同通道 Pair → 分组 3×3 → 细化残差 R → 空间门 G；D = A⊙G + R | 每尺度一组；式 (2)–(5) |
| 解码 / 头 | 1×1 侧向到 64 通道 → FPN 深到浅 → P1–P4 拼成 256 通道 → 轻量头 2 类 Logits | 上采样回 H×W |
| 损失 | 未加权 CE + Dice，λ=1.0；**不称边界感知损失** | 式 (6)，Ŷ vs Y |
| 输出 | 变化二值图 | 验证集 F1 选模，测试集只评一次 |
| 部署 | ONNX → TensorRT 10.7；主报 Jetson Orin Nano Super 15 W、FP16、无 CUDA Graph | 10.96 ms / 91.2 FPS / 13.2 W；**仅模型推理** |

**数据流一句话**：

> I1, I2 → 共享 RepViT 四尺度 → 各尺度 PSDG（A⊙G+R）→ FPN 融合 → 2 类头 → 变化掩膜。

**推理与训练不一致**：

- 有：RepViT 训练侧结构重参数化思想；**投稿实验用 timm 层级接口，部署按实际导出图测量，不把分支折叠当贡献**
- 无 TTA；部署种子预先指定 42，不按测试集挑最好种子
- FP32 vs AMP-FP16 在 2048 张测试图 F1：90.6942% vs 90.6926%；ONNX 与 PyTorch 掩膜一致率 100%

## 3. 传统方法与 SOTA 的真局限

| 类别 | 代表方法（正文已引） | 它在本失败上怎么死 | 对应失败 | 文献 |
|------|----------------------|--------------------|----------|------|
| 传统 | CVA / PCA | 高分下尺度跨度大、辐射不稳，代数差异分不开建筑增减与扰动 | A/B | [4][5] |
| 精度向深度 | STANet / SNUNet / BIT / ChangeFormer | 注意力与密集连接抬 F1，也抬参数与部署成本；ChangeFormer 文献 41.02 M | C | [7]–[10] |

| 最像的一篇 | TinyCD | **只差这一句：**TinyCD 是另一套浅层时空混合，参数更小、文献 F1 更高；本文是统一 RepViT 下把多尺度/门控做成可开关因素，并补板端。不是同协议赢它 | C | [11] |

**文献里已有、本文不再冒充首创**：孪生差分、FPN、RepViT/重参数化、CE+Dice、LEVIR/WHU 基准、TensorRT 导出。

## 4. 方法骨架

| 模块 | 解决哪条失败 / 约束 | 关键运算 | 可被替换成 | 若不做会怎样 |
|------|---------------------|----------|------------|--------------|
| M1 共享 RepViT-M0.9 | 工程约束：参数/显存；为消融提供统一骨干 | 共享 θ 的四尺度编码 | MobileNet / TinyCD 骨干 | **L0**。换成别的骨干，2×2 归因故事要重做 |
| M2 多尺度差分+FPN | 失败 A、失败 C（归因主体） | 四尺度差分 → 侧向 64 → 自上而下相加 | 单尺度直接差分（表 2 已做） | F1 从 89.95 掉到 77.89（−12.06） |
| M3 PSDG | 失败 B | Pair + 分组卷积 → R、G；D=A⊙G+R | 直接差分（表 2/表 4 已做）；未做 SE/1×1 内部替代 | LEVIR：F1 −0.73、R −1.91；WHU：F1 **+2.03**（关掉更好） |
| M4 CE+Dice | 正样本 4.2%，单 CE 偏背景 | λ=1.0 复合；无独立边界项 | 单 CE（**未做消融**） | 未测 |
| M5 TensorRT 板端 | 失败 C | FP16 无 Graph 主报 | 只报 FLOPs | 失去工程卖点 |

**整体创新级别：窄 L2**（不是 L3，也不是纯 L1）。  
依据：新计算主要是 PSDG 的同通道分组配对 + 加法残差；真正可防守的是 **2×2 可证伪归因** 和 **WHU 上关掉门控更好**。RepViT 与标准 FPN 是载体。交互效应为负，禁止「协同」。

## 5. 卖点三元组（只认 3 条）

正文贡献条写了 4 条。本表淘汰贡献 1「构建 RepViT」为 L0，见下「明确不声称」。

### 卖点 1：多尺度差分是精度主体（L2，归因型）

- **一句话**：统一骨干下，关掉 FPN 会掉 12.06 个百分点 F1，不是堆模块叙事。
- **动机**：失败 C。轻量文献混堆，无法回答涨点来自哪。
- **设计**：四尺度差分 → 1×1 到 64 → FPN 深到浅 → 拼 256 通道。与「单尺度直接差分」只差是否用 P1–P4。骨干在四格消融中保持不变。
- **验证**：表 2，三种子、验证集选模、测试一次。直接差分下单尺度 77.89 → 多尺度 89.95（+12.06 F1，+17.95 IoU）。门控条件下多尺度仍 +11.73 F1。
- **理论依据**：深层下采样损伤小目标与边界（引言）；FPN 把深层语义送回浅层空间（Lin 等，正文 [20]）。依据接到「为何必须多尺度」，不是接到「FPN 是本文发明」。
- **适用边界**：WHU 未做单尺度格，**不能**把「多尺度是主体」外推到 WHU。
- **级别**：L2（归因），机制差偏窄。

### 卖点 2：PSDG 的收益是数据集条件性的（L2，含负向）

- **一句话**：LEVIR 补召回，WHU 官方空间测试区 F1 −2.03，应能关闭。
- **动机**：失败 B。绝对差分漏弱变化；加法残差 R 可在 A≈0 处补响应，也在空背景加虚警。
- **设计**：同序通道交错 → 分组数=Cl 的 3×3 → R；G=σ(1×1(R))；D=A⊙G+R。与直接差分只差式 (5)。与「拼接后标准卷积」的差：同语义通道配对、组内 2×3×3。
- **验证**：表 2 多尺度下 +0.73 F1、+1.91 R、−0.54 P；小变化切片 +2.67 F1、+4.78 R；无变化切片虚警增加。表 4 WHU：F1 91.86→89.83（−2.03），P −3.56，无变化切片虚警约 2.4 倍。交互 −0.33，不支持强协同。
- **理论依据**：正文把权衡写进式 (5) 后，不是只挂文献号。
- **适用边界**：大面积、高对比变化（WHU 类）应关门控。禁止「通用伪变化抑制」。
- **级别**：L2。正文贡献 2 目前只写 LEVIR 漏检、没把 WHU 边界写进该条 → 对齐断裂，见 §6。

### 卖点 3：指定板、指定精度的模型推理闭环（L2 工程，CSCD 认）

- **一句话**：Jetson 15 W、TensorRT FP16、无 CUDA Graph：10.96 ms / 91.2 FPS / 13.2 W，不是只报 FLOPs。
- **动机**：失败 C。fvcore FLOPs 只是下界（表 5 注）。
- **设计**：种子 42 预指定导出 ONNX → TensorRT 10.7；主报无 Graph；8.78 ms 仅峰值。
- **验证**：表 5 工作站 FP32 15.31 ms / 3.66 GFLOPs 下界；表 6 板端。测量不含相机与配准。25 W 未测。
- **理论依据**：内存带宽与算子调度使理论复杂度不等于时延（引言）。
- **适用边界**：仅模型推理；不可暗示整条巡检流水线 91.2 FPS。
- **级别**：L2 工程。无板端则本条删除。

**明确不声称**：

- 不声称 LEVIR 上 F1/IoU/参数量优于 TinyCD
- 不声称同协议复现了表 3 任一公开方法
- 不声称多尺度与门控强协同
- 不声称 RepViT 本身是创新；不声称执行了额外全网结构重参数化转换
- 不声称门控跨数据集抑制伪变化
- 不声称 FLOPs 精确；不声称 25 W 或含配准的端到端
- 不声称 CE+Dice 是新损失
