# papers/

每篇自己的稿一份 dossier。只放诊断表，不放正文 docx / 大图。

```bash
./scripts/new-paper.sh SHORT_NAME
```

```text
papers/<短名>/
├── README.md
├── A-解剖.md
├── B-压力测试.md
├── C-判决书.md
├── 灵魂拷问.md      ← 可选
└── 防守补丁.md      ← 可选
```
