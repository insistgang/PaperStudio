## 1. 打分尺（先读锚点，再打分）

只打三个主分。小数禁止。打分时在「证据」列粘贴 A/B 中的短句。

### 创新度 1–10（看机制，不看形容词）

| 分 | 锚点 |
|----|------|
| 1–2 | L0 换皮 |
| 3–4 | L1 积木，无交互证据 |
| 5 | 窄 L2：有一个可关掉的机制，但很像已有差分/注意力 |

### 实验扎实度 1–10

| 分 | 锚点 |

| 1–2 | 单数据集，无消融 |

### 写作规范 1–10

| 分 | 锚点 |
|----|------|
| 1–3 | 题目不通、贡献流水账、摘要痛点正文没有、乱加粗 |

### 合成

加权：**0.4×创新 + 0.4×实验 + 0.2×写作**，保留 1 位小数。

**合成分：【 】**

否决项（任一触发，合成分作废，直接「不可投该梯度」）：

- [ ] B 存在未关闭死穴
- [ ] 主对比表把非同协议数字当排序依据

- [ ] 实验扎实度 ≤4 却想投 G2+

## 5. 终审判决

三选一，圈一个：

### □ 可投

条件：最佳匹配 = 用户意向；B 无死穴；半防均有正文补丁；写作必改已关或可在排版阶段关闭。  
行动：走知识库 `/Users/insistgang/Documents/knowledge/02-Thesis/Writing/投稿检查清单_2026-02-07.md` 或目标刊专表；**仍须用户授权才改 docx / 上传系统**。

### □ 有条件可投

条件：必补实验 E? 完成，或接受对应降声称。  
降声称草稿：【例如「不与 TinyCD 比 SOTA，只做量级对照 + 2×2 归因」】  
完成前禁止投稿。

### □ 不可投（该意向刊）

原因：【梯度错配 / 未关闭死穴 / 数据未冻结】  
改道：【改投 G? / 暂停 / 回 A 重定卖点】

**最大拒稿理由预告**（即使可投也写，用来写 Cover Letter 时避开吹牛）：

> 【审稿人最可能的一句：】

**Cover Letter 只允许强调的 2–3 个词**：

2. 【】
3. 【】

禁止在 Cover Letter 出现：SOTA、填补空白、显著优于未同协议方法。
